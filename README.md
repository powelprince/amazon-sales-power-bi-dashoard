# amazon-sales-power-bi-dashoard
Power BI: Amazon Sales Analysis Dashboard

🧾 Short Description

An end-to-end Power BI analytics project that builds an interactive sales dashboard for Amazon sales data. It covers importing, cleaning, modeling, analyzing, and visualizing e-commerce sales metrics to derive business insights and trends.

🛠️ Tech Stack

Microsoft Power BI Desktop – dashboard creation & visualization

Power Query – data transformation & cleaning

DAX (Data Analysis Expressions) – calculations and measures

CSV / Excel Datasets – raw sales data source

GitHub – version control and project files (expected for repo)

📁 Data Source

Likely Amazon sales datasets with fields such as:

Order date, product category, quantity, revenue

Customer reviews & ratings

Category / sub-category sales metrics
(You’d typically find sample CSV/Excel data uploaded in the repo)

⭐ Features

📈 Interactive Sales Dashboard: filterable by time (year/quarter/month), categories, and products

📊 Trend Analysis: visualize overall and category-wise sales performance

🏆 Top Products Insights: bar/column charts for best-selling products

📅 Time Intelligence KPIs: Year-to-Date (YTD), Quarter-to-Date (QTD) sales, etc.

📌 Dynamic Visual Filters: slicers for category, date range, and product

📌 Data Modeling: building relationships between tables and data transformation
